# G7：App 前端功能和界面

> 状态：首轮实现完成并通过质检  
> 前置依赖：G3–G6（均已完成）

G7 将把已完成的生成、测量、保存和 PDF 能力接入桌面 App。达成共识的内容持续写入
[G7 产品与实施计划](./g7-product-plan.md)，代码按
[G7 实施计划](./g7-implementation-plan.md) 分模块落地，结果见
[G7 实施结果](./g7-implementation-result.md)。

已确认的核心方向：

- 左侧保留 Agent 对话，右侧为可展开/收起的 A4 简历 Canvas；
- Canvas 支持像文档编辑器一样直接修改文字；
- bullet 或整段经历可拖入聊天区，交给 Agent 定向修改；
- Agent 修改以待确认版本展示，Canvas 下方提供接受/拒绝；
- 本地工作稿自动加密保存，历史聊天通过 Artifact 卡片恢复对应本地简历；
- App 提供本地检查点回退，云端只展示每份 Resume 的当前内容；
- 固定资产字段只读，尝试编辑时解释原因并提供聊天修改入口；
- 界面持续说明本地草稿、云端当前内容和导出文件的区别；
- 删除聊天时保留关联本地简历，后续由左侧栏独立入口继续访问；
- 全部界面沿用现有主题和组件；卡片只能选择背景或边框之一；
- AI 修改使用低透明度绿色荧光笔高亮，禁止边框式高亮；
- 高级详情、保存到云端和导出入口在 Canvas 展开后显示于展开/收起按钮左侧，并与其同一行；
- 顶部不常驻质量指标，高级详情只展示页面占比、最低尾行、事实完整性和 JD 覆盖；
- 不提供独立“继续优化版面”按钮，后续优化统一通过聊天发起。
