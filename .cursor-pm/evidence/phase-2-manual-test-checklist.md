# Phase 2 手测流程

按顺序做，每条记 **过 / 失败 / 跳过**。UI 快扫可只做 **C**，业务闭环以 **A** 为主。

## 自动化（先跑再手测）

在 **worktree** `prd-profile-pref-app-takeover` 根目录：

```bash
npm run qa:phase-2
```

| 覆盖 | 说明 |
|------|------|
| A1/A2/C 部分 | 源码合约 + **Electron UI QA**（设置/Profile/偏好/DialogSelect/底栏边距/审批 fixture） |
| A1/A4 部分 | Profile 单测 + UI QA 保存与 **sessionStorage 持久化 + reload** |
| A2 部分 | Preference 单测 + UI QA 新增偏好全流程 |
| A3/A5 部分 | UI QA：偏好 **ApprovalCard** 点「接受并执行」；**行为建议**种子卡片展示 |
| B 部分 | 材料库 core/导航单测 + UI QA **材料库 fixture 挂载** |

仅跑 UI：`npm run qa:phase-2:ui`（会先 `desktop:build`）。

**搁置（与 Phase 4 联测批次一起测，不挡 Phase 2 关闭）**：A3-chat、A4-cold、B2–B3、C4。自动化仍见 `npm run qa:phase-2` 结束提示。

## A. 必测 — Profile + Preference（Phase 2 核心）

### A1 个人资料（Profile）

1. 打开 **设置 → 个人资料**
2. 修改 1～2 个字段（姓名、联系方式等）
3. 若有 **职业目标**，新增或改一条
4. **下拉**：职业阶段、默认语言、默认风格 → 展开菜单为圆角主题列表（非系统蓝底原生菜单）
5. 提交 → 若有审批，在对话或 **ApprovalCard** 里 **批准**
6. 关闭弹窗再打开 → 数据是否保留、展示是否正确
7. 同步条：待同步 / 冲突 / 失败时文案与「使用服务端版本」链接是否正常

### A2 长期偏好（Preference）

1. **设置 → 偏好**
2. **列表页**：底部「查看本轮生效说明 / 关闭」与弹窗边缘有留白（不贴角）
3. **新增偏好** → 规则类型、作用域下拉为主题列表 → 填值 → 走提案 → 批准
4. 列表是否出现；若有编辑/停用，各点一次
5. **Esc** 关闭 → 焦点是否回到设置（不「丢焦点」）

### A3 审批

- Profile 或 Pref 提交后，若聊天区有 **ApprovalCard**：
  - 至少 **批准** 一条成功
  - 可选：再 **拒绝** 一条，看是否未写入、能否再提

### A4 持久化 / 同步观感（单机）

1. 保存后看状态文案（已同步 / 待同步 / 冲突等，有就记原文）
2. 完全退出 App 再开 → Profile + 偏好是否还在

### A5 偏好建议（可选）

- 偏好弹窗里若有 **「可能的偏好」**（灯泡）：试 **保存 / 不保存且不再提示**
- 若没有 → 写 **「A5 跳过，无建议」**

## B. 建议测 — 材料库回归（约 5 分钟）

### B1

侧栏 **材料库** → 能打开、不白屏

### B2

导入一张图/PDF，或打开已有材料 → 详情正常

### B3

若有 OCR 低置信 → 进审阅再返回，不崩溃

## C. UI 快扫 — 设置壳 + 主题下拉（`DialogSelect`）

> 每隔一段时间扫一眼即可；不必每条都测业务保存。

### C1 设置总览

- 设置弹窗 **~920×560**、左侧导航 + 右侧滚动；关闭按钮可点
- 从设置打开 Profile / 偏好后，**Esc** 仍先关子弹窗，再关设置；焦点合理

### C2 已换主题下拉的入口（点开一项即可）

| 区域 | 建议点开的下拉 |
|------|----------------|
| 设置 → 个人资料 → 编辑 | 职业阶段 |
| 设置 → 偏好 → 新增 | 规则类型 |
| 投递跟踪 → 新建/编辑投递 | 投递方式 或 关联 JD |
| 投递详情 → 面试/笔记/提醒 | 类型 或 状态 |
| 经历库 → 编辑经历 | 类别；开始/结束时间精度 |
| Agent 任务循环弹窗（若能打开） | 检查间隔 或 授权有效期 |

### C3 下拉交互（任一处抽测）

- 列表不裁切（可滚出弹窗滚动区）
- 选中项有勾；点击外部关闭
- 键盘：↑↓ 移动、Enter 选中、Esc 关闭

### C4 仍为原生 `<select>`（已知，低优先级）

- 简历仓库 / 材料库 / 岗位库 **顶栏筛选**
- 经历库 **筛选 Popover**

失败请记：**页面 + 下拉字段名 + 截图**。
